# GFP蛋白工程优化竞赛 - 荧光破界者队伍
## 📋 项目简介
本仓库为**合成生物学GFP蛋白工程优化竞赛**的可复现代码仓库，由「荧光破界者」队伍提交。

本项目实现了从**赛事数据加载→历史靶点挖掘→双目标序列生成→全流程合规性校验→最终提交序列筛选**的完整闭环，所有设计逻辑、算法管线、执行步骤完全开源可复现。

## 🎯 赛事信息
- **赛事名称**：合成生物学GFP蛋白工程优化竞赛
- **队伍名称**：荧光破界者
- **设计目标**：设计兼具「高荧光亮度」与「72℃热稳定性」的GFP家族蛋白序列
- **最终评分**：相对荧光亮度 × 72℃热稳定性保留率
